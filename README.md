## 🔐 چرا POPVPN X؟

* **🚀 بدون وابستگی (Zero Dependencies):** تمام مراحل پایپ‌لاین صرفاً با کتابخانه استاندارد پایتون (3.9+) اجرا می‌شود و نیازی به نصب هیچ پکیج اضافه‌ای نیست.
* **🛡️ پردازش امنیتی هوشمند:** شناسایی خودکار هاست‌های خصوصی، کلید‌های جعلی (`00000000-0000-0000-0000-000000000000`)، کانفیگ‌های `allowInsecure=1` و نشانه‌های خطر دیگر.
* **🔍 تست زنده (Liveness Probe):** بررسی هم‌زمانه TCP/TLS، سنجش پینگ واقعی و حذف نودهای مرده با امکان محدودیت تعداد پروکسی.
* **📊 خروجی‌های متنوع و ساختاریافته:** تولید لینک‌های پایه، Base64، پروفایل‌های پیشرفته Clash (Mihomo), فایل‌های JSON بر پایه sing-box و لیست‌های فیلترشده بر اساس امتیاز.
* **🗺️ شناسایی خودکار کشورها:** تشخیص اسم کشور، پرچم، کد دو حروفی با استفاده از داده‌های پیش‌پردازش‌شده (hash map).
* **📈 تاریخچه و نمودار روند:** ذخیره کامل عملکرد و نمایش روند تغییرات در داشبورد و فایل‌های خروجی.

## 🛠️ Core Features

* **Zero Runtime Dependencies:** Runs purely on Python standard library with a modular, maintainable architecture.
* **Smart Security Layer:** Detects and filters insecure configurations (allowInsecure, private IPs, weak credentials).
* **Liveness Probe:** Tests TCP/TLS connectivity to ensure servers are alive; marks dead nodes for removal.
* **Multi-Format Output:** Generates multiple universal formats (Base64, Plain, Clash, sing-box) for maximum compatibility.
* **Geographic Intelligence:** Automatic country flag, code and name detection from URI remarks.
* **Analytics Dashboard:** Real-time web dashboard with runtime statistics and interactive charts.
